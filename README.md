## Structure

```
app-docs/
├── index.html
├── README.md
└── routine-five/
    ├── privacy.html       (FR)
    └── privacy.en.html    (EN)
```

To add a new app: create a folder `<app-slug>/`, add `privacy.html` (and any other legal docs), update the index.
